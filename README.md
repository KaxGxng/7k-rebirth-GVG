# 7K Combo - ระบบจัดการโพย Guild War (Seven Knights Re:BIRTH)

เว็บแอปพลิเคชันสำหรับสร้าง จัดการ และแชร์โพยตี **Guild War (GVG)** ของเกม **Seven Knights Re:BIRTH** (ออกแบบตามแนวทาง [7K Combo](https://7k-combo.pages.dev))

## ฟีเจอร์หลัก
1. **ระบบแยกโพยตามกิลด์ (Multi-Guild `/g/:shortId`)**
   - สร้างโพยกิลด์ใหม่ได้ภายใน 10 วินาทีจากหน้าแรก
   - แยกสิทธิ์ **รหัสผู้ดูแลกิลด์ (Admin Password)** สำหรับเพิ่ม/แก้ไข/ลบทีม และ **รหัสดูโพย (Viewer Password Lock)** สำหรับล็อกไม่ให้กิลด์คู่แข่งแอบส่อง
2. **จัดแผนการรบและคิวสกิลตามระบบ Seven Knights Re:BIRTH**
   - รองรับแผนการรบ `1-4` (หน้า 1 หลัง 4), `2-3` (หน้า 2 หลัง 3), `3-2` (หน้า 3 หลัง 2), และ `4-1` (หน้า 4 หลัง 1)
   - จำกัดตัวละครสูงสุด 3 ตัวต่อทีมในโหมด Guild War พร้อมตั้งลำดับการกดสกิล **บน (T)** / **ล่าง (B)** ลำดับ `1 -> 2 -> 3`
   - ตั้งค่าอุปกรณ์สวมใส่รายตัวละคร: **เซ็ตอุปกรณ์ (ครบ 9 เซ็ต)**, **แหวน (ครบ 32 วง)**, **ออฟชั่นแนะนำ** และ **คำแนะนำวิธีเล่น (Note)**
3. **ระบบค้นหาด้วยชื่อตัวละคร สัตว์เลี้ยง และชื่อเล่น (Nicknames) + ตัวกรองประเภททีม**
   - ค้นหาด้วยชื่อจริงหรือชื่อเล่นยอดนิยม เช่น `ลิง` (ซุนหงอคง), `เกล` / `ป๋า` (เกลลิดัส), `พาลานอส`, `คางแหลม` (ซองจินอู), `แฝด` (บรันซ์ & บรันเซล), `ยานแม่` (แร็ดกริด), `ตุ้ม` (เสี่ยวเฉี่ยว), `พระแม่` (โรซี่)
   - กรองตามประเภททีมป้องกัน: `ทั้งหมด`, `ถึก`, `เวทย์`, `กายภาพ`, `อื่น ๆ`
4. **ฐานข้อมูลครบทุกตัวละครและไอเทมพร้อมรูปภาพในตัว (Offline-Ready Assets)**
   - ตัวละคร 128 ตัว (O7K, Awake, ทองบน, ทองล่าง, Epic Awake, อีปิค)
   - สัตว์เลี้ยง 28 ตัว (เลเจนด์, อีปิค)
   - เซ็ตอุปกรณ์ 9 เซ็ต และแหวน 32 วง

## วิธีรันใช้งานบนเครื่อง (Local Development)

```bash
# ติดตั้งแพ็กเกจ
npm install

# รันเซิร์ฟเวอร์ (Frontend + Backend API ที่พอร์ต 3000)
npm run dev
```

เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`
- โพยตัวอย่างพร้อมใช้งานทันที: `http://localhost:3000/g/meta7k` (รหัสแอดมินทดสอบ: `1234`)
